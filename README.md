# nanowire

Header-only protocol core on [nanom](https://github.com/yoavbendor/nanom): zero-copy views and builders for Ethernet/VLAN/IPv4/IPv6/UDP/TCP, SOME/IP (SD, TP), AUTOSAR PDU-over-IP and container PDUs, plus zero-copy reassembly. Shared by [nanoshark](https://github.com/yoavbendor/nanoshark) (read) and [nanocraft](https://github.com/yoavbendor/nanocraft) (craft).

Work in progress.
